# 常规汇报封面

封面用于介绍主题。默认仅有主题标题、一句可选副标题和有来源的署名/日期；没有署名或日期就留空，不编造。标题建议 8–24 个汉字，最多两行；副标题一行。受众问题、核心判断、汇报目标、目录、证据、适用边界和结论进入正文或内部编辑字段，不放上封面。

采用大面积留白和一个清晰的标题区域。沿用用户选定的配色、字体和材质；不放多模块卡片、图标清单、指标面板、目录、复杂外框或底部结论栏。主视觉可省略。

## 整套字体与字号层级

已有母版沿用原来的字体与正文角色尺寸，不因封面调整而重设正文。新建无母版页面默认中文思源黑体，西文 Arial，整套每个文字角色固定字重及字号；下表为 16:9 幻灯片建议值。

| 角色 | 建议字号 | 字重 |
| --- | --- | --- |
| 封面标题 | 40–48 pt | Bold |
| 正文页标题 | 28–32 pt | Bold |
| 副标题 | 20–24 pt | Regular |
| 模块标题 | 20–24 pt | Semibold |
| 正文 | 18–22 pt | Regular |
| 图表标签 | 14–16 pt | Regular |
| 关键数字 | 32–40 pt | Bold |
| 底部结论 | 18–20 pt | Semibold |
| 页脚、署名与日期 | 12–14 pt | Regular |

独立简洁封面示例仅使用标题和副标题，继承深蓝与金色，不附加缺失的作者/日期。示例文案为「腾讯 2026 年第二季度／业绩与策略简报」「增长质量与 AI 投入节奏」。

## 生效范围与校验

新拆页的 PagePlan 将封面标题设为主题名；分组写作与整套写作都执行简洁封面检查。可见字段仅使用 title、subtitle，以及可选的 lead（仅用于真实署名/日期），其他正文内容字段留空；内部 audienceQuestion、oneSentenceAnswer、bridgeToNext 和 sourceRefs 可保留，但不进入 verbatimText。

校验只对新生成的文案启用，旧项目及已锁定文案不会被静默删改。正在运行的制作任务不重载；待任务结束重启服务后，新拆页采用新规则。

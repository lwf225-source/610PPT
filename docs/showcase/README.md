# 610PPT case gallery / 案例展示

This directory collects complete, reviewable presentation examples made with the 610PPT workflow. Each case keeps its source story, visual directions, and review notes together so the gallery shows more than isolated screenshots.

这里收录通过 610PPT 工作流完成、可逐项审阅的完整演示案例。每个案例会同时保留内容主线、视觉方向和审核说明，而不只展示零散截图。
